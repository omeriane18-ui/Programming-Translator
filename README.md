# dotcode — مترجم أكواد بالذكاء الاصطناعي (مجاني بالكامل)

موقع ثابت (static site) يترجم الكود بين لغات البرمجة عن طريق Groq API المجاني. ينشر مجاناً على GitHub Pages، والشكل قابل للتخصيص بالكامل (لون، حجم، تقوس زوايا، خط...) بنفس روح تخصيص أنظمة لينكس (rice).

الملفات كلها هذي، ولا شيء غيرها:

```
index.html   -> الصفحة والهيكل
style.css    -> التصميم والثيمات
app.js       -> منطق الترجمة + محرك الثيمات
robots.txt   -> لمحركات البحث
sitemap.xml  -> لمحركات البحث
```

لا باك-إند، لا قاعدة بيانات، لا استضافة مدفوعة. كل شيء يشتغل من متصفح الزائر مباشرة.

## كيف يشتغل

كل زائر يحتاج مفتاح Groq مجاني خاص فيه (مو مفتاحك أنت) باش يقدر يترجم:

1. يروح لـ https://console.groq.com/keys
2. يسوي حساب مجاني ويولّد مفتاح API (يبدأ بـ `gsk_...`)
3. يلصقه في خانة "Connect your Groq API key" فوق صفحة الترجمة

المفتاح يتحفظ فقط في متصفح الزائر (`localStorage`)، ما يوصل لأي سيرفر تاعي أنا. الاتصال يروح مباشرة من متصفح الزائر لـ Groq.

ملاحظة: أسماء نماذج Groq (نوع `llama-3.3-70b-versatile`) ممكن تتغير مع الوقت. إذا توقف النموذج، شوف القائمة المحدّثة في https://console.groq.com/docs/models وبدّل القيمة الافتراضية في `index.html`، أو خلي الزائر يبدّلها بروحه من نفس الحقل.

## قبل ما تنشر، بدّل هذي الأشياء

**اللغات المجانية والمدفوعة** — افتح `app.js` ودور على `LANGUAGES` فوق. أول 7 لغات عندها `free: true` هي المجانية، والباقي `free: false` (مقفولة، تبان بأيقونة 🔒 وتوجّه المستخدم يراسلك). زيد أو احذف أو رتب كيفما تحب، بنفس الشكل:

```js
{ id: "typescript", name: "TypeScript", free: false },
```

**رابط الموقع الحقيقي** (هذا مهم جداً للـ SEO) — بعد ما تعرف رابط GitHub Pages تاعك، بدّل في 3 أماكن: `index.html` (كل مكان فيه `https://dotcode.example/`)، `robots.txt`، و`sitemap.xml`.

**البريد ونظام الاشتراك** — البريد `omeriane0@gmail.com` موجود في `index.html` (قسم اللغات، النافذة المنبثقة، About، Footer). إذا بدّلته لاحقاً دور عليه واستبدله بكل الأماكن.

تنبيه صريح: الموقع ثابت (بدون سيرفر) فما فيه نظام دفع/تحقق آلي حقيقي — القفل حالياً هو "قفل واجهة" بس، يوجّه الزائر يراسلك يدوياً. كافي كبداية (MVP): تستلم الإيميل، تتفق مع الزبون، وتفتحله يدوياً. إذا حبيت لاحقاً نظام دفع آلي حقيقي (Stripe/Gumroad + مفتاح ترخيص)، يحتاج خطوة إضافية بسيطة (serverless function).

## النشر على GitHub Pages

1. سوي Repository جديد، مثلاً باسم `dotcode`.
2. ارفع الملفات لجذر المستودع مباشرة (بدون مجلد فرعي).
3. من إعدادات المستودع: Settings → Pages، اختار Source: `Deploy from a branch`، Branch: `main` والمجلد `/ (root)`، واحفظ.
4. بعد دقيقة أو دقيقتين رح يعطيك رابط شكله:
   `https://YOUR-GITHUB-USERNAME.github.io/dotcode/`
5. رجع بدّل الرابط في الملفات الثلاثة المذكورين فوق وارفعهم من جديد (commit جديد).

هذا كل شيء. الموقع الآن منشور ومجاني بالكامل — GitHub Pages مجاني، Groq مجاني للزائر.

اختياري: من نفس صفحة Pages تقدر تضيف Custom domain إذا اشتريت دومين لاحقاً.

## باش يتصدر محرك البحث

الموقع مجهز مسبقاً بـ:
- Meta title / description / keywords
- Open Graph + Twitter Card
- JSON-LD schema (`SoftwareApplication`)
- `robots.txt` و`sitemap.xml`
- HTML دلالي (h1 واحد، تسلسل عناوين منطقي)

بعد النشر:

1. سجّل في Google Search Console: https://search.google.com/search-console
2. أضف رابط موقعك وتحقق من الملكية
3. من قسم Sitemaps، أضف `sitemap.xml`
4. اطلب "Request Indexing" للصفحة الرئيسية
5. اختياري: سجّل نفس الشيء في Bing Webmaster Tools

النتائج عادة تبان خلال أيام لأسابيع، وتتحسن أكثر إذا الموقع حصل على روابط من مواقع أخرى.

## التخصيص (Theming / "rice")

قسم "rice" في الموقع يسمح لأي زائر يبدّل: اللون الرئيسي، تقوس الزوايا، كثافة العناصر، حجم الخط، خط الواجهة وخط الكود، وفيه 6 ثيمات جاهزة (Amber CRT, Nord, Dracula, Gruvbox, Solarized, Paper Light). كل هذا يتحفظ في متصفح الزائر بس، ما يأثر على زوار آخرين. إذا حبيت تزيد ثيم جديد، افتح `app.js` وزيد عنصر في `PRESETS`.

## اختبار محلي

ما تحتاج أي أداة، افتح `index.html` مباشرة في المتصفح، أو (أفضل، تفادي مشاكل CORS بسيطة) شغّل سيرفر محلي:

```bash
python3 -m http.server 8000
```

وافتح `http://localhost:8000`
