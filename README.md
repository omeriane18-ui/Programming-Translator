# dotcode — مترجم أكواد بالذكاء الاصطناعي (مجاني بالكامل)

موقع ثابت (Static Site) يترجم الكود بين لغات البرمجة باستخدام Groq API المجاني، ينشر مجاناً على GitHub Pages، ومظهره قابل للتخصيص بالكامل (ألوان، حجم، خط، تقوس الزوايا...) بنفس روح تخصيص أنظمة لينكس (rice).

**الملفات (4 ملفات فقط + ملفي SEO):**
```
index.html   -> الصفحة والهيكل
style.css    -> كل التصميم والثيمات
app.js       -> منطق الترجمة + محرك الثيمات
README.md    -> هذا الملف
robots.txt   -> لمحركات البحث
sitemap.xml  -> لمحركات البحث
```

لا يوجد باك-إند، لا قاعدة بيانات، لا استضافة مدفوعة. كل شيء يعمل من متصفح الزائر مباشرة.

---

## 1) كيف يعمل الموقع؟

كل زائر يحتاج **مفتاح Groq مجاني خاص به** (وليس مفتاحك أنت) ليستخدم الترجمة:
1. يدخل الزائر إلى https://console.groq.com/keys
2. ينشئ حساب مجاني ويولّد مفتاح API (يبدأ بـ `gsk_...`)
3. يلصقه في خانة "Connect your Groq API key" أعلى صفحة الترجمة

المفتاح يُحفظ فقط في متصفح الزائر (`localStorage`) ولا يُرسل لأي سيرفر تابع لك — الاتصال يذهب مباشرة من متصفح الزائر إلى Groq.

> **ملاحظة مهمة:** أسماء نماذج Groq (مثل `llama-3.3-70b-versatile`) قد تتغير مع الوقت. إذا توقف النموذج عن العمل، شوف القائمة المحدثة في https://console.groq.com/docs/models وغيّر القيمة الافتراضية في حقل "Model" داخل `index.html`، أو اطلب من الزائر تغييرها بنفسه من نفس الحقل في الموقع.

## 2) قبل النشر — عدّل هذه الأشياء

### أ) اللغات المجانية والمدفوعة
افتح `app.js` وابحث عن `LANGUAGES` في الأعلى. أول 7 لغات فيها `free: true` هي المجانية، والباقي `free: false` (مقفولة، تظهر أيقونة 🔒ويوجّه المستخدم لمراسلتك على omeriane0@gmail.com).

أضف/احذف/أعد ترتيب اللغات كما تريد بنفس الشكل:
```js
{ id: "typescript", name: "TypeScript", free: false },
```

### ب) رابط الموقع الحقيقي (مهم جداً للـ SEO)
بعد ما تعرف رابط GitHub Pages تاعك (الخطوة 3)، بدّل في 3 أماكن:
- `index.html`: كل مكان فيه `https://dotcode.example/`
- `robots.txt`: بدّل `YOUR-GITHUB-USERNAME` و`YOUR-REPO-NAME`
- `sitemap.xml`: نفس الشيء

### ج) البريد ونظام الاشتراك المدفوع
البريد `omeriane0@gmail.com` موجود بالفعل في 3 أماكن (قسم اللغات، النافذة المنبثقة، About، Footer). إذا بدّلته لاحقاً، ابحث عن `omeriane0@gmail.com` في `index.html` واستبدله.

**تنبيه صريح:** بما أن الموقع ثابت (بدون سيرفر)، لا يوجد نظام دفع/تحقق حقيقي مؤتمت — القفل حالياً هو "قفل واجهة" فقط (يوجّه الزائر ليراسلك يدوياً). هذا كافٍ تماماً كبداية (MVP): تستلم الإيميل، تتفق مع الزبون، وتفتحله يدوياً (مثلاً ترسله نسخة معدّلة، أو كود خصم لاحقاً). إذا أردت لاحقاً نظام دفع واشتراك آلي حقيقي (Stripe/Gumroad + مفتاح ترخيص)، هذا يتطلب خطوة تالية بسيطة (serverless function) ويمكن نبنيها مع بعض لاحقاً.

## 3) النشر المجاني على GitHub Pages

1. أنشئ مستودع (Repository) جديد على GitHub، مثلاً باسم `dotcode`.
2. ارفع ملفات هذا الـ zip الخمسة إلى جذر المستودع مباشرة (بدون مجلد فرعي).
3. من إعدادات المستودع: **Settings → Pages**
   - Source: `Deploy from a branch`
   - Branch: `main` والمجلد `/ (root)`
   - احفظ
4. بعد دقيقة أو دقيقتين رح يعطيك رابط بالشكل:
   `https://YOUR-GITHUB-USERNAME.github.io/dotcode/`
5. عدّل الرابط في الملفات الثلاثة المذكورة بالأعلى (index.html, robots.txt, sitemap.xml) وارفعهم مرة ثانية (commit جديد).

هذا كل شيء — الموقع الآن منشور ومجاني بالكامل (GitHub Pages مجاني، Groq مجاني للزائر).

### (اختياري) دومين خاص
من نفس صفحة Pages تقدر تضيف Custom domain لو اشتريت دومين لاحقاً، وGitHub يعطيك تعليمات DNS تلقائياً.

## 4) باش يتصدر الموقع محرك البحث (SEO)

الموقع مجهز مسبقاً بـ:
- Meta title / description / keywords
- Open Graph + Twitter Card tags
- JSON-LD schema (`SoftwareApplication`) يفهمها Google مباشرة
- `robots.txt` و`sitemap.xml`
- HTML دلالي (h1 واحد، تسلسل عناوين منطقي)

خطوات إضافية بعد النشر (تستغرق 10 دقائق وتفرق كثير):

1. سجّل في **Google Search Console**: https://search.google.com/search-console
2. أضف رابط موقعك (Property) وتحقق من الملكية (Google يعطيك طريقة عبر meta tag أو ملف HTML)
3. من قسم **Sitemaps** داخل Search Console، أضف: `sitemap.xml`
4. اطلب "Request Indexing" للصفحة الرئيسية
5. (اختياري) سجّل نفس الشيء في **Bing Webmaster Tools**

النتائج على Google عادة تظهر خلال أيام لأسابيع، وتتحسن أكثر إذا حصل الموقع على روابط من مواقع أخرى (مثلاً منشور عنه في مجتمعات مبرمجين، Reddit، Product Hunt، إلخ).

## 5) التخصيص (Theming / "Rice")

قسم "rice" في الموقع يسمح لأي زائر بتغيير:
- اللون الرئيسي (accent)
- تقوس الزوايا (radius)
- كثافة/تباعد العناصر (density)
- حجم الخط
- خط الواجهة وخط الكود
- 6 ثيمات جاهزة (Amber CRT, Nord, Dracula, Gruvbox, Solarized, Paper Light)

كل هذا محفوظ في متصفح الزائر فقط (لا يؤثر على الزوار الآخرين). إذا أردت تضيف ثيم جاهز جديد، افتح `app.js` وأضف عنصر جديد في مصفوفة `PRESETS`.

---

## 6) اختبار محلي قبل الرفع

ما تحتاج أي أداة، فقط افتح `index.html` مباشرة في المتصفح، أو (أفضل، لتفادي مشاكل CORS بسيطة) شغّل سيرفر محلي بسيط:
```bash
python3 -m http.server 8000
```
وافتح `http://localhost:8000`
